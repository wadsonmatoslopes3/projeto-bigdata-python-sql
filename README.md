# Processamento de Big Data - Dados.BR

Este projeto automatiza a leitura e carga de grandes volumes de dados públicos.

## 🚀 O que este projeto faz?
- Processa arquivos CSV de grande porte (1GB+).
- Importa registros para banco de dados MySQL.
- Cruza informações de empresas e naturezas jurídicas.

## 🛠️ Tecnologias
- **Python** (Pandas, SQLAlchemy)
- **MySQL** (XAMPP / phpMyAdmin)
